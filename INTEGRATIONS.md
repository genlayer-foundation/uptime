## Inbound

| From | Route | Auth | What |
|---|---|---|---|
| Vercel Cron | `GET /api/cron/heartbeat` (hourly) | `Authorization: Bearer $CRON_SECRET` (fail-closed) | submit a tick. **Stands down when `DATABASE_URL` is set**: the Heartbeat is then the system job dispatched by `/api/cron/dispatch` |
| Vercel Cron | `GET /api/cron/dispatch` (every 5 min) | same | start due job runs (gate checked per run); creates the public "Bradbury Heartbeat" job on first use when `HEARTBEAT_CONTRACT` + `PRIVATE_KEY` are set |
| Vercel Cron | `GET /api/cron/settle` (hourly at :15) | same | batched pool charge; returns `{ enabled: false }` unless `POOL_CHARGING_ENABLED=1` |
| Vercel Cron | `GET /api/cron/reconcile` | same | Heartbeat: grade decided txs, fire appeals (Postgres `heartbeat_probes`; KV fallback). Jobs: decide pending steps, start the next step, finish runs (reported under `jobs`) |
| Browsers / agents (wallet sign-in) | `POST /api/auth/nonce` (GET alias), `POST /api/auth/verify` `{ message, signature }`, `POST /api/auth/logout`, `GET /api/me` (alias `/api/auth/me`) | SIWE (EIP-4361, EOA signatures), single-use 10-min nonce, domain must match the host; then an httpOnly HMAC cookie `uptime_session` signed with `SESSION_SECRET` (>= 32 chars; without it every user route answers 503) | `frontend/src/lib/jobs/auth/session.ts:114` (`verifySiwe`) |
| Signed-in owners | `GET`/`POST /api/jobs`, `GET`/`PATCH`/`DELETE /api/jobs/{id}`, `POST /api/jobs/{id}/pause\|resume` | session cookie; mutations refuse a foreign `Origin` | job CRUD. **Studio: 403 unless the wallet is in `STUDIO_ALLOWLIST` (env, comma-separated; unset = nobody)**. Operators in `UPTIME_ADMIN_WALLETS` may also `GET /api/jobs?all=1`, read any job and its runs, and pause any job, quota `STUDIO_MAX_JOBS_PER_WALLET`. | Public / Grafana | `GET /api/jobs?public=1`, `GET /api/jobs/{id}`, `GET /api/jobs/{id}/runs?limit&format=json\|rows` | none for public jobs; owner session otherwise (404 for anyone else) | public example jobs; run history; `format=rows` = one flat row per step run (heartbeat row fields + the jobs UI `RunRow` fields) |
| Anyone | `GET /api/presets?network=` | none | prefilled job templates with that network's preset contract addresses, availability per network, the pool address |
| Public / Grafana (Infinity) | `GET /api/heartbeat[?hours=N][&format=rows]` | none, read-only | summary JSON, or one row per probe |
| Bradbury validators (inside `probe_fetch` / `probe_llm`) | `GET /heartbeat/{static.json,lighthouse.txt,bakery.txt}` | none | frozen fixtures; base URL set at contract deploy |
| Signed-in owners (SIWE cookie `uptime_session`, `SESSION_SECRET`) | `GET`/`POST /api/alerts/recipients`, `DELETE /api/alerts/recipients/{id}` | session; 503 unless `MAILER_ENABLED` and wired | list / add (sends one confirmation email; max 3 per wallet) / remove alert addresses |
| Signed-in owners | `GET`/`PUT /api/alerts/jobs/{jobId}` | session + job owner (backend `jobOwner` lookup; 503 without it) | which confirmed addresses get a job's alerts, `failAfter` |
| Email recipients (link in the confirmation mail) | `GET`/`POST /api/alerts/verify?r&x&t` | HMAC token (`MAILER_TOKEN_SECRET`), bound to row + address + wallet, 24 h expiry | GET shows a button, POST confirms |
| Email recipients / mail clients (RFC 8058 one-click) | `GET`/`POST /api/alerts/unsubscribe?e&t` | HMAC token per address (`MAILER_TOKEN_SECRET`) | POST adds the address to the suppression list; identical answer whatever the token |
| Cron (not scheduled yet) | `GET /api/alerts/bounces` | `Authorization: Bearer $CRON_SECRET` (fail-closed) | merge the provider's suppression list into ours |

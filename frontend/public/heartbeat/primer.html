GenLayer, a primer

GenLayer is a blockchain whose Intelligent Contracts can read the web and call large language models. Validators run those calls independently and reach agreement on the result.

Reading time: 4 minutes. 12 sections in the full guide, 3 of them summarized here.

How Optimistic Democracy decides

Optimistic Democracy is GenLayer's consensus mechanism. Inspired by Condorcet's Jury Theorem, it uses validator recomputation and majority agreement as a safety net for AI-driven computations.

A leader validator executes the transaction and proposes a result. The other validators assess the leader's proposal using the Equivalence Principle and vote on it.

If a participant disagrees with the result, they can appeal during the Finality Window by submitting a request and providing a bond. A new group of validators then joins the original ones and re-evaluates the transaction. Each round of an escalating appeal doubles the number of validators.

Validators run the consensus infrastructure. Delegators stake their tokens with a validator without running infrastructure, and earn rewards proportional to their stake, minus the validator's operational fee.

Glossary

Leader: the validator that proposes a result. Equivalence Principle: the rule validators use to decide whether two results agree. Finality Window: the period during which a result can be appealed.
